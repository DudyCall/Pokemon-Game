## Button Layout & Physical Controls

The 8BitDo SN30 Pro features a retro-inspired ergonomic layout with a full set of modern controls (16 physical buttons / 19 discrete inputs):

### Face Button Orientation (Important)

To avoid label confusion across Nintendo/X-Input naming styles, use this physical orientation reference:

| Physical Position | Printed Label on SN30 Pro |
| :--- | :--- |
| **South (Bottom)** | `B` |
| **East (Right)** | `A` |
| **North (Top)** | `X` |
| **West (Left)** | `Y` |

> In other words: **B is the bottom button**, **A is the right button**, **X is the top button**, and **Y is the left button**.

| Section | Button(s) | Description / Function |
| :--- | :--- | :--- |
| **Action Buttons** | `A`, `B`, `X`, `Y` | 4-button diamond face layout (`B` South, `A` East, `X` North, `Y` West). |
| **Directional Pad** | `D-Pad` (Up, Down, Left, Right) | Classic cross-style digital directional pad. |
| **Analog Sticks** | `Left Stick`, `Right Stick` | Dual clickable 360-degree analog thumbsticks. |
| **Thumbstick Clicks**| `L3`, `R3` | Inward click on left and right thumbsticks respectively. |
| **Shoulder Buttons** | `L`, `R` | Digital left and right upper bumper shoulder buttons. |
| **Triggers** | `L2`, `R2` | Lower digital/analog trigger shoulder buttons. |
| **Navigation / Menu**| `Select` (`-`) / `Start` (`+`)| Standard Select (Minus) and Start (Plus) buttons. |
| **Special Buttons** | `Star (*)` | Turbo assignment button / Screenshot button (Switch mode). |
| | `Home` | System Home button / Power & Turbo LED indicator ring. |
| **Top Edge** | `Pair` Button | Dedicated sync button located next to the USB-C charging port. |
| **Status LEDs** | 4 Bottom Indicator LEDs | Show player number, connection status, and pairing modes. |

## Power Management

| Action | Shortcut / Method |
| :--- | :--- |
| **Turn On Controller** | Press `Start` (or hold mode button + `Start` to switch OS mode). |
| **Turn Off Controller** | Press and hold `Start` for **3 seconds**. |
| **Force Power Off / Reset** | Press and hold `Start` for **8 seconds**. |

## System Compatibility & Pairing Modes

> **Quick Mode Switch Key:**
> * **Switch:** `Y + Start`
> * **Windows:** `X + Start`
> * **Android:** `B + Start`
> * **Apple:** `B + Start`

---

### 1. Nintendo Switch Mode
* **Requirements / Limitations:** 
  * Compatible with Nintendo Switch / Switch OLED / Switch Lite.
  * NFC (Amiibo), IR motion camera, HD Rumble, and wireless wake-up are *not* supported.
  * Status LEDs indicate the player slot (1st LED = P1, 1st & 2nd LEDs = P2, etc. — up to 8 players).

#### Bluetooth Connection:
1. Press and hold `Y + Start` to power on the controller in Switch mode. LEDs will begin cycling from left to right.
2. Hold the top **`Pair`** button for **3 seconds** to enter pairing mode. The LEDs will pause briefly and resume cycling. *(Required for first-time pairing only)*.
3. On your Switch Home Menu, go to **Controllers** &rarr; **Change Grip/Order**.
4. The controller LED becomes solid when successfully connected.

#### Wired Connection:
1. Ensure `System Settings` &rarr; `Controllers and Sensors` &rarr; **`Pro Controller Wired Communication`** is enabled on your Switch.
2. Press and hold `Y + Start` to power on the controller.
3. Connect the controller to a USB port on the Switch dock using a USB-C cable.

---

### 2. Windows Mode (X-Input)
* **System Requirement:** Windows 10 (Build 1903) or newer.

#### Bluetooth Connection:
1. Press and hold `X + Start` to turn on the controller. The **1st and 2nd LEDs** will start blinking.
2. Hold the top **`Pair`** button for **3 seconds** to enter pairing mode. LEDs will cycle from left to right. *(Required for first-time pairing only)*.
3. Open Windows **Bluetooth & Other Devices Settings**, enable Bluetooth, and pair with **`8BitDo SN30 Pro`**.
4. The LEDs will turn solid when connected.

#### Wired Connection:
1. Press and hold `X + Start` to turn on the controller (LEDs 1 & 2 blink).
2. Connect the controller to any USB port on your PC via USB-C.

---

### 3. Android Mode (D-Input)
* **System Requirement:** Android 9.0 or above.

#### Bluetooth Connection:
1. Press and hold `B + Start` to turn on the controller. The **1st LED** will start blinking.
2. Hold the top **`Pair`** button for **3 seconds** to enter pairing mode. LEDs cycle from left to right. *(Required for first-time pairing only)*.
3. Open Android **Bluetooth Settings** and tap to pair with **`8BitDo SN30 Pro`**.
4. The 1st LED will remain solid once connected.

#### Wired Connection:
1. Ensure your Android device supports USB OTG (On-The-Go).
2. Press and hold `B + Start` to turn on the controller.
3. Connect via USB-C (or OTG adapter) to your Android device.

---

### 4. Apple Devices Mode
* **System Requirements:** iOS 16.3+, iPadOS 16.3+, tvOS 16.3+, or macOS 13.2+.

#### Bluetooth Connection:
1. Press and hold `B + Start` to turn on the controller. The **1st LED** will blink.
2. Hold the top **`Pair`** button for **3 seconds** to enter pairing mode (LEDs rotate left to right).
3. Open **Bluetooth Settings** on your Apple device and connect to **`8BitDo SN30 Pro`**.
4. The LED will illuminate solid upon successful pairing.

#### Wired Connection:
* *Note: USB wired connection is available on macOS or iPadOS devices equipped with USB-C ports.*
1. Press and hold `B + Start` to turn on the controller.
2. Connect directly to your Mac or iPad via a USB-C cable.

## Turbo Functionality

The Turbo feature allows rapid automated inputs without manual button mashing.

* **Supported Buttons:** `A`, `B`, `X`, `Y`, `L`, `R`, `L3`, `R3`
* **Switch Note:** Turbo functionality is *not* available in Nintendo Switch mode (the Star button serves as Screenshot).
* **Persistence:** Turbo configurations are temporary and reset back to default upon power down or disconnection.

---

### Manual Turbo Mode (Rapid fire while holding button)
* **Activate:** Hold desired target button &rarr; Press the **`Star (*)`** button once.  
  *(The Home ring LED will blink rapidly during input).*
* **Deactivate:** Hold target button &rarr; Press the **`Star (*)`** button once.  
  *(The Home LED turns off).*

### Auto Turbo Mode (Continuous automated firing without holding)
* **Activate:** Hold desired target button &rarr; Press the **`Star (*)`** button **twice**.  
  *(The Home ring LED will blink rapidly continuously).*
* **Deactivate:** Hold target button &rarr; Press the **`Star (*)`** button **twice**.  
  *(The Home LED turns off).*

## LED Indicator Reference

| LED Pattern | Meaning |
| :--- | :--- |
| **Rotating / Cycling (Left to Right)** | Controller is in Bluetooth pairing sync mode. |
| **1st & 2nd LEDs Blinking** | Ready to connect in Windows (X-Input) mode. |
| **1st LED Blinking** | Ready to connect in Android / Apple mode. |
| **Rotating Cycle (Switch)** | Ready to connect in Nintendo Switch mode. |
| **Solid LED(s)** | Connection established successfully (or player number index on Switch). |
| **Rapid Blinking Home LED** | Turbo / Auto-Turbo active on an input. |
